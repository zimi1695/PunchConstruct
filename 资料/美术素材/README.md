## 药水

三份药水采用五张源图：先古药水直接使用交接图 `资料/交接/瓶中船与人工制品/先古药水.png`（256×256），图标按 Lanczos 缩到70×70，大图原样导出，不再调色；浑浊机油使用 `药水/痊愈药水_图标.png`（78×75）与 `药水/痊愈药水_大图.png`（256×256），只把内容物转深灰；拳手炖汤使用 `药水/士兵炖汤_图标.png`（76×73）与 `药水/士兵炖汤_大图.png`（256×256），整体去色。图标导出原尺寸（先古药水除外），另生成白色轮廓；大图导出256×256。士兵炖汤的原生大图相对图标有约180°色相偏移，脚本先校正再去色；痊愈药水大图与图标同色相，不做色相校正，否则内容物会偏出灰色掩膜。先古药水与浑浊机油不再共用格挡药水源图，旧的 `格挡药水_图标.png`／`格挡药水_大图.png` 已移入 `资料/历史/旧稿`。所有输出保留PNG源文件，游戏读 `.ctex`。
