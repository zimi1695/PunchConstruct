# 录像脚本（0.5.1）

这些脚本用于录制 0.5.1 的卡牌、遗物与药水展示视频。它们依赖模组内置的调试命令 `pcdeck`，不需要安装额外工具，也不需要手动一张张加牌。

## 使用前

1. 启用 PunchConstruct 0.5.1（本地 `mods/PunchConstruct` 需为含愚者搬运牌与药水展示的最新构建；私有测试条目 3835179658 上的旧 0.5.1 不含这两项，重传前请勿用旧包录制）。
2. 开始一局构装体。先完成涅奥的祝福，然后停留在第一层地图上，不要进入战斗。
3. 按反引号键（`` ` ``）或单引号键（`'`）打开控制台；`Shift+8` 也可以。
4. 输入 `pcdeck` 回车，可看到命令说明；输入 `help pcdeck` 可查看同一说明。

## 三个脚本

| 文件 | 命令 | 结果 |
| --- | --- | --- |
| `01-全部内容.txt` | `pcdeck all` | 牌组 98 张（每种 1 张），遗物 22 件（每种 1 件），药水 3 种（每种 1 瓶） |
| `02-0.5.1改动.txt` | `pcdeck changes` | 牌组 22 张，遗物 7 件，药水 3 种（0.4.28 → 0.5.1 的改动与新增） |
| `03-原创内容.txt` | `pcdeck mod` | 牌组 26 张，遗物 9 件，药水 3 种（只含模组原创内容） |

命令执行后，打开牌组视图（默认 `D`）核对卡牌数量；遗物在屏幕顶部的遗物栏核对，药水在药水栏核对。`pcdeck all` 的 98 张包含构装体池里的原生适配牌与 10 张愚者搬运牌，不只是原创牌；22 件遗物包含起始遗物、先古遗物和共享遗物变体；3 种药水为先古药水、浑浊机油、拳手炖汤。`pcdeck mod` 只展示原创：26 张原创卡（23 张原创设计＋灼热铁斩波、小斩波、东尼斩波），9 件遗物（7 件原创＋损毁头盔、螺线飞镖两件银色换色），3 种药水；按作者口径排除铁斩波（原版牌换图）、核心电涌／万能药（一代素材复用原版牌）、震荡、观者／愚者／其余搬运牌与其余共享遗物变体。

## 注意

- `pcdeck` 会直接替换当前牌组、全部遗物与全部药水，并跳过所有“获得时”效果。因此潘多拉、巨大扭蛋、树叶药膏、尼奥护符等不会反过来改变展示用的牌组或遗物。
- 只能在战斗外使用；战斗中会提示 `Run pcdeck outside combat, at the start of a run.`。
- 联机时命令会走主机权威的 `ConsoleCmdGameAction`；录像建议单机，避免等待同步。
- 脚本 02 不包含原生遗物古牙（ArchaicTooth）的适配改动：古牙不属于构装体遗物池，`pcdeck changes` 不会把它加入遗物栏。如要展示古牙，请在正常流程中获取，或单独用原生遗物命令添加。
- 这些命令是调试工具，不是正式玩法内容；录制结束后直接退出本局即可，不需要保留存档。
